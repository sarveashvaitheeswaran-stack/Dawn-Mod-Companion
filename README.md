## 🌅 Why This Exists

Somewhere between the third failed escape attempt and the fifth suspicious glance from a guard, a thought appears: *there has to be a smarter way to enjoy this game.*

*Back to the the Dawn* is a game about patience, planning, and personality. It rewards the player who notices small details — the way a certain character reacts when you mention food, the way a schedule shifts when rain falls, the way a single conversation can unlock an entire story branch. It is, in many ways, a game about observation.

Traditional trainer utilities treat that richness as an afterthought. They flip switches. They multiply numbers. They get the job done and vanish. This project takes a different route: it builds a **field companion** that respects the game's texture while still giving you the freedom to bend the rules when curiosity wins.

The goal is simple — let you explore every corner of the prison without burning a weekend on a single locked door.

---

## 🧭 Concept & Philosophy

Imagine walking into a library where every book is written in a language you almost understand. A trainer, in its classic form, is a translation dictionary. Useful, but cold. The **Field Companion Edition** is the librarian sitting beside you, whispering context, offering shortcuts, and occasionally nudging you toward a chapter you would have skipped.

Three principles guide every design decision:

1. **Quiet by default.** Nothing pops up uninvited. The companion waits until you ask.
2. **Transparent mechanics.** Every toggle explains what it changes, in plain language.
3. **Reversible everywhere.** Nothing writes permanent changes to your save without an explicit, separate confirmation.

This is not a tool that plays the game for you. It is a tool that hands you the wheel and points at the horizon.

## 🧰 The Companion Toolkit

Below is a deeper look at the modules that make up the toolkit. Each module is independent: enable only what you need.

### Stat Whisperer

Adjust core attributes — strength, agility, intellect, charisma, and the less obvious ones that the game hides behind flavor text. Changes apply live, and a "snapshot" button lets you store the current values before you experiment. If something feels off, restore the snapshot and carry on.

### Pouch Expander

Inventory limits are a classic source of frustration. The Pouch Expander does not simply remove the cap; it lets you choose a comfortable ceiling, with visual warnings when you approach it. This keeps the experience grounded while still removing the sharpest edges.

### Relationship Compass

Every character in the yard has opinions, moods, and hidden thresholds. The Relationship Compass displays these as a soft gradient rather than a hard number, so you can see momentum without reducing people to digits. Adjustable, but never forced.

### Schedule Weaver

Time in the prison flows on rails. The Schedule Weaver lets you nudge the clock forward or backward by increments, or jump to a specific block of the day. It is useful when you want to catch a specific event without idling for twenty minutes.

### Map Memory

Reveals locations you have already visited, and optionally marks points of interest you have brushed past. It does not reveal the entire map on first launch — exploration still matters.

### Save Sentinel

A lightweight save manager that creates timestamped backups before any major change. If a toggle ever produces an unexpected result, you have a clean restore point waiting.

## 📐 Responsive Interface

The interface reshapes itself around your screen the way water reshapes around a stone. On a wide monitor, every module sits side by side in a calm grid. On a narrow laptop display or a side window, modules stack vertically and collapse into accordions.

Key behaviors:

- Fluid grid that reflows at three breakpoints
- Collapsible sections that remember their last state
- Keyboard navigation for every control
- High-contrast theme for late-night sessions
- Compact mode for users who prefer a single column of switches

Nothing is hidden behind a maze of menus. If a feature exists, it has a visible home.

## 🗂️ Configuration & Profiles

Profiles are the companion's quiet superpower. Each profile stores a full set of module states, so you can switch between, say, a "story mode" profile with minimal changes and a "sandbox" profile where everything is open.

Profiles live as readable files. You can copy them, share them, or archive them for later. Nothing is locked in a proprietary format.

Recommended profile ideas:

- **Purist** — only time adjustment enabled
- **Explorer** — map memory and relationship compass active
- **Storyteller** — stat whisperer and pouch expander tuned gently
- **Sandbox** — every module unlocked, for players who want to see everything

## 🚀 Getting Started Without a Manual

You will not find a wall of terminal commands here. The companion is designed to be approachable from the first click.

A gentle path for newcomers:

1. Obtain the companion package through the distribution channel linked on this page.
2. Place it in a folder you can find again — a dedicated tools directory works well.
3. Launch it before or after the game; the companion detects an active session automatically.
4. Start with a single module. Get comfortable. Add more when you feel ready.
5. Create a profile once you find a combination you like.

If anything feels unclear, the always-on assistance channel exists precisely for that moment.

## 🎨 Design Language

The visual identity leans into warmth rather than sterility. Colors are muted, typography is generous, and animations are short enough to feel responsive without becoming distracting.

Design pillars:

- **Calm contrast** — dark and light themes built side by side
- **Readable density** — information is grouped, never crammed
- **Motion with meaning** — transitions explain state changes
- **Accessible by default** — focus rings, scalable text, and reduced-motion mode

Even a utility deserves to look like someone cared about it.

## ⚡ Performance Notes

The companion is intentionally lightweight. It runs as a separate process, communicates with the game through a thin bridge, and avoids polling loops that would waste cycles.

Performance characteristics:

- Idle memory footprint measured in tens of megabytes
- No disk writes unless a profile or backup changes
- No network calls during normal operation
- Graceful shutdown that flushes state before exit

If you notice unexpected resource usage, that is a bug worth reporting.

## ❓ Frequently Asked Questions

**Is this the same as every other trainer?**
No. It shares DNA with trainers, but the philosophy is different. It is built as a companion first and a utility second.

**Will it work with my save files?**
Yes, and it creates backups before touching anything important.

**Can I disable modules I do not want?**
Every module has an independent toggle. Nothing runs unless you ask it to.

**Does it require an internet connection?**
No. Normal operation is fully local.

**What if I find a bug?**
Report it through the assistance channel. Reproduction steps and a screenshot go a long way.

**Is there a portable version?**
The distribution is self-contained. There is no separate installer to chase.
